## 📖 Introduction

This repository documents 100 consecutive days of practicing Python, from the very first `print("Hello, World!")` to building a fully tested, authenticated REST API backed by a real database.

Each day includes:
- 📝 **Notes**: a clear explanation of the day's concept
- 💻 **Code**: a working, runnable example
- 🛠️ **Projects**: small applications that tie multiple concepts together

## 📂 How to Use This Repo

Each day lives in its own folder, named `DayXX Topic Name/`, containing:
- `DayXX Notes.md`: concept explanation
- `DayXX <Topic>.py`: runnable example code

Clone the repo and explore any day:

```bash
git clone https://github.com/HereIsMuhammad/100-days-of-python.git
cd 100-days-of-python
cd Day50-OOP-Library-Management-System
python *.py
```
